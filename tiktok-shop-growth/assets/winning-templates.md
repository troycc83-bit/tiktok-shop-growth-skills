# 跑赢骨架库（Winning Templates）

> 由 `tiktok-weekly-review` 在复盘时回流写入：某个骨架/脚本跑出好结果，就把它的结构记在这里。
> 只记**可复用的叙事骨架**，不记具体产品文案。每次仿写前先读本文件。

## 记录格式

```
### [骨架名] — 记录日期
- 来源视频 / 骨架类型：
- 验证结果：（播放/完播/点击/转化等，有数据就填，无则标注"定性跑赢"）
- 适用卖点 / 场景：
- Hook 类型：
- 时间轴骨架：
- 为什么跑赢（复盘判断）：
- 可复用要点：
```
