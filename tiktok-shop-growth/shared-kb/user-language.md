# 用户语言库（Voice of Customer）

> 由 `tiktok-market-research` 从竞品评论/差评中挖来的**真实买家措辞**。
> 仿写时直接用作 hook 和口播文案素材——用买家自己的话，不用营销腔。

## 记录格式

```
### [品类/卖点主题]
- 痛点原话（英文原文）：
  - "..."
- 高频搜索词 / hashtag：
- 未被满足的场景：
- 好评里反复夸的点：
- 差评里反复骂的点：
- 来源平台 / 日期：
```

## 已积累素材

### 降噪需求与痛点（美国用户，2026-11-18 调研）

- 核心使用场景（占比，来源：喜马拉雅白皮书，中国市场，仅作方向参考）：通勤 73.2% / 户外步行 53.7% / 办公室校园 51.4% / 住所 50%
- 美国侧需求信号（来源：Deloitte 转引）约 70% 专业人士认为降噪音频设备提升生产力；约 93% 消费者购买前查评论
- 痛点原话 / 高频措辞（英文语境，来自 Reddit 汇总与评测媒体）：
  - "ANC lowers voices; it does not remove them."（降噪消不掉人声）
  - "A leaking flagship loses to a well-sealed budget pair."（贴合度比芯片重要）
  - "Battery life only counts with ANC on."（标称续航都是关降噪测的）
  - "pressure and mild pain after an hour or two"（小耳道用户戴久了胀痛）
  - "audible hiss in quiet environments"（安静环境有底噪嘶声）
  - "vacuum-like pressure in the ears"（真空般的耳压感）
  - "can't hear traffic / approaching train"（户外听不到车/火车的安全焦虑）
  - "buds tend to fail after 12–18 months"（大牌耐用性问题）
  - "touch controls trigger mode changes by accident"（误触切换降噪）
  - "69% use ANC even when not playing audio"（不为听声音，只为获得安静）
- 未被满足的场景：
  - 开放式办公降人声（当前 ANC 对中高频人声无力）
  - 户外运动既要环境音安全、又要一定降噪——开放式耳机（open-ear）被视为合理替代
  - 侧睡/整夜降噪（睡眠耳机细分，客单价可到 $80–140）
  - 小耳道人群的舒适贴合
- 差评里反复骂的点：贴合度、耳压胀痛、底噪嘶声、误触、续航虚标、耐用性（12–18 个月故障）、App 依赖联网
- 好评里反复夸的点：强降噪深度、稳固贴合、长途飞行/通勤安静、预算款（Tozo/Anker/EarFun）性价比惊人
- 高频搜索词 / hashtag：noise cancelling earbuds, ANC earbuds, open ear earbuds, transparency mode, ear pressure, sleep earbuds, commuter earbuds
- 来源平台 / 日期：Google/Reddit/Amazon 公开页 + 评测媒体（hifireport / soundproofpoint / eCoustics / electricfieldsfestival 等），2026-11-18
- 可信度标注：Reddit 共识与评测实测为中等可信；喜马拉雅数据为中国市场，仅作方向参考；具体销量/GMV 未获取，不编造
