# 计划模型说明（Planning Model）

> 指标关系与公式骨架。供销售计划 Skill 生成表格时引用，不含假设数字。

## 双模型并列的意义

TikTok Shop 的 GMV 有三条主要来源路径，单人团队通常无力全押，需看清每条路径的杠杆：

1. **达人带货模型**：靠达人数量与单人产出驱动，杠杆在"建联 + seeding 效率"
2. **内容流量模型**：靠自营视频的量与转化驱动，杠杆在"内容质量 + 发布频率"
3. **商品卡承接**：靠搜索/推荐流量，杠杆在"标题关键词 + 主图 + 评价"

## 公式骨架

### 达人产出模型
```
达人贡献 GMV = 出单达人数 × 单人平均出单数 × 客单价
出单达人数 = 建联达人数 × 采纳率 × 出单率
净收入贡献 = 达人贡献 GMV × (1 - 佣金率)
```
可调指标：建联数、采纳率、出单率、单人产出、佣金率。

### 内容流量模型
```
内容贡献 GMV = 发布视频数 × 平均播放量 × 商品点击率 × 下单转化率 × 客单价
```
可调指标：视频数、播放量、CTR、CVR。
注意：播放量是不可控结果，行动清单里应放"发视频数"这种可控动作。

### 商品卡模型
```
商品卡 GMV = 曝光 × CTR × CVR × 客单价
```
可调指标：曝光（受 SEO/评价影响）、CTR（主图/标题）、CVR（价格/评价）。

### 毛利校验
```
单件毛利 = 客单价 × (1 - 平台佣金 - 达人佣金) - 采购成本 - 头程 - 广告分摊 - 退货损耗
毛利率 = 单件毛利 / 客单价
```
所有成本项由用户提供，不代填。

## 三档预测逻辑

- **保守**：杠杆指标取用户认为"较易达到"的水平
- **基准**：取用户认为"正常发挥"的水平
- **乐观**：取用户认为"超常发挥"的水平

档位的具体数字由用户定义，Skill 不提供行业均值假设。

## 每周 3 件事的设计原则

单人团队时间有限，行动清单只放**可控且高杠杆**的动作，每周围绕：
- 达人：本周建联 N 个 / 寄样 N 个
- 内容：本周产出 N 条视频 / 拆解 N 条爆款
- 数据：本周复盘一次，回流骨架

N 的具体值由用户填。
