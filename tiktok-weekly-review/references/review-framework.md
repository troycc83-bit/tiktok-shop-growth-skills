# 复盘框架（Review Framework）

> 逐层定位偏差的方法。核心是"找最大偏差层"，而不是泛泛看整体。

## 漏斗分层（找出哪一环掉了）

### 内容漏斗
```
视频发布数 → 平均播放 → 3秒留存 → 商品点击率 → 下单转化率 → 成交
```
逐层对比计划 vs 实际，找出降幅最大的一层。

- 发布数不够 → 执行问题（可控动作不足）
- 播放低 → 分发/hook 问题（前 3 秒没抓住）
- 点击低 → 内容说服力问题（没激发兴趣）
- 转化低 → 商品页/价格/评价问题

### 达人漏斗
```
建联数 → 采纳率 → 出单数 → 单人产出 → 达人 GMV 贡献
```
- 建联少 → 动作量不足
- 采纳率低 → 达人筛选或话术问题
- 出单率低 → 佣金吸引力或产品匹配问题

## 归因分类（对最大偏差层）

| 类别 | 典型信号 |
|------|---------|
| 内容问题 | 播放高但点击低；3 秒留存差 |
| 选品/产品 | 点击有但转化低；差评集中 |
| 达人问题 | 建联/采纳/出单某层掉 |
| 流量投放 | 曝光不足、预算提前耗尽 |

每类归因必须附数据依据；数据不足以支撑时标为"推测"并说明。

## 资产回流判断

一条内容值得回流成骨架，需满足至少一条：
- 转化率明显高于近期平均
- 同一骨架被多次验证有效
- 跑出了过去没做过的漏斗突破（如首次突破某点击率）

回流时只记**结构**：Hook 类型、时间轴、说服目的顺序、战术使用。具体产品文案不记。

## 下周 3 件事

只放可控动作，围绕：
- 达人：建联 N / 寄样 N
- 内容：产视频 N / 拆爆款 N
- 数据：复盘一次 / 回流骨架

N 由用户根据实际情况填，Skill 不代定。
